### 👋 About Me

I'm a **Machine Learning & Data Science practitioner** pursuing my MS in Data Science at **Northeastern University** (Khoury College of Computer Sciences). I focus on building end-to-end ML systems — from feature engineering and model training to MLOps pipelines and deployment.

- 🤖 Building **GridSage** — a carbon-aware workload orchestration system using Multi-Agent Reinforcement Learning (Google Expo, April 2026)
- 📄 **IEEE-published** research on NLP-driven stock market prediction using sentiment analysis
- 🏦 Previously at **RBL Bank** — ML models achieving **87% precision** across **300K+ records**
- 🏗️ Currently at **Larsen & Toubro** — automated data pipelines on Microsoft Fabric Lakehouse
- ⚖️ Building **CourtAccess AI** — document processing pipeline for multilingual legal PDF translation
- 🌆 Based in Boston | Originally from Mumbai
